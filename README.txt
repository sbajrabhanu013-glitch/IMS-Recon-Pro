IMS Recon Pro | @BAJRABHANU

How to run:
1. Install Python 3.11 or 3.12.
2. Open this folder in Command Prompt.
3. Run: pip install -r requirements.txt
4. Run: streamlit run IMS_Recon_Pro.py

Login users:
MainAdmin / Adminpwd
User1 / Userpwd1
User2 / Userpwd2

Recommended workflow:
1. Login.
2. Client Setup.
3. Upload Purchase Register.
4. Upload GST IMS Utility .xlsm after importing IMS JSON in the official utility, or upload raw IMS JSON.
5. Reconciliation Workspace > Start IMS Reconciliation.
6. Review IMS Action Center.
7. Reports & Export > Download complete workbook.

Phase 1 generates the final action report. Phase 2 can write status back into GST Utility after final testing of editable Status columns.
